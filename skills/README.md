# Skills

Cada skill é um diretório com um `SKILL.md`. O instalador procura até três níveis a partir desta pasta:

- `skills/<nome>/SKILL.md`
- `skills/<categoria>/<nome>/SKILL.md`
- `skills/<categoria>/<grupo>/<nome>/SKILL.md`

Um `SKILL.md` mais raso esconde o que estiver dentro da mesma pasta. Este arquivo não é uma skill e não é copiado.

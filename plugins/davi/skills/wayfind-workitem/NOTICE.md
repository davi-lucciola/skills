# Notice

- `SKILL.md` and `references/map.md` adapt the `wayfinder` skill from [mattpocock/skills](https://github.com/mattpocock/skills) (`skills/engineering/wayfinder/`, MIT, Copyright (c) 2026 Matt Pocock). The map is a Jira Epic whose children are the work items (Story, Bug, Habilitador) and the refinement tickets that block them (the upstream decision tickets): blocking uses Jira's "blocks" links from each ticket to the work item it refines, each kind is its own Jira issue type with a short Novo → A Fazer → Desenvolvendo → Concluído workflow (Decisão, Pesquisa, Protótipo with the `wayfinder:task` label; Task for manual work with no PR), resolved by this plugin's `grilling` + `domain-modeling`, `research`, `prototype`, and `design-workitem` skills (prototype in Claude Design). Charting cuts the work items first, then the refinement tickets each one waits on; `refine-workitem` also creates and resolves them. The map and its tickets are written in pt-BR and carry a project label. The `next` and `status` verbs extend it to route work items through the work item flow, and absorb the earlier `ask-workitem` skill.

Criteria 15 (issue type), 16 (labels and language), 17 (refinement done), and 18 (refinement ticket linked) are this plugin's own.
